# AI 데이터 표준 사전 v1.0

> 16개 고유 필드의 의미, 표준명, 타입, 키, 도메인을 팀에서 확정한다.

## 1. 작성 원칙

- 표준 컬럼명은 동일 개념에 동일 이름을 사용한다.
- 명명 규칙은 팀 전체에서 통일한다.
- 업무 의미가 불명확한 컬럼은 임의 해석하지 않는다.
- 타입과 NULL 허용 여부도 함께 결정한다.

## 2. 표준 명명 규칙

### 작성 예시
- 표준 컬럼명: `snake_case`
- 식별자: `_id`
- Boolean: `is_`, `has_`
- 날짜: `_date`
- 일시: `_at` 또는 `_datetime` 중 하나로 통일
- 불필요한 약어 사용 금지

### 팀 확정
- 표기 방식:
- ID 규칙:
- 날짜/일시 규칙:
- Boolean 규칙:
